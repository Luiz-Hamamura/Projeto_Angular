# Projeto Angular

Projeto desenvolvido para a disciplina **Design de Interfaces Humano/Computador**.

O projeto consiste em uma aplicação para uma concessionária, tendo como primeira etapa o desenvolvimento do **cadastro de clientes**.

## Funcionalidades

* Cadastro de clientes;
* Preenchimento dos dados do cliente;
* Validação dos campos obrigatórios;
* Mensagem de confirmação após o cadastro.

## Campos do cadastro

* Nome;
* CPF;
* Telefone;
* E-mail;
* Endereço.

## Tecnologias utilizadas

* Angular;
* TypeScript;
* HTML;
* CSS;
* PrimeNG;
* Node.js;
* Angular CLI.
